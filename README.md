# Awak AI Studio: website

Company profile + lead-generation site for an AI-augmented digital agency in Medan, aimed at UMKM/SME owners. Bahasa Indonesia, mobile-first, WhatsApp-first conversion, blog for long-term SEO.

**Stack:** Next.js 14 (App Router) · TypeScript (strict) · Tailwind CSS · Supabase (Postgres) · Resend · Vercel

The brand name is not final in the brief. It lives in one place, `lib/site.ts`: rename it there.

## Quick start

```bash
nvm use            # Node 20+
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
```

The site runs with **no env vars at all**: WhatsApp buttons fall back to `/kontak`, the blog uses seed posts from `content/posts.ts`, and the lead form works in dev mode (logs to the console). Add credentials as you go.

| Script | What it does |
|---|---|
| `npm run dev` | Dev server |
| `npm run build` / `npm start` | Production build / serve |
| `npm run lint` | ESLint (next/core-web-vitals + TypeScript) |
| `npm run typecheck` | `tsc --noEmit` |

## Go-live checklist

1. **WhatsApp:** set `NEXT_PUBLIC_WHATSAPP_NUMBER` (e.g. `6281234567890`). All buttons, the floating pill, and prefilled messages switch over.
2. **Supabase:** create a project, run `supabase/migrations/0001_init.sql` in the SQL editor, then set `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, and `SUPABASE_SERVICE_ROLE_KEY` (server only, never `NEXT_PUBLIC_`).
3. **Email:** create a Resend account, verify your domain, set `RESEND_API_KEY`, `RESEND_FROM`, `LEAD_NOTIFY_EMAIL`.
4. **WhatsApp notification of new leads (optional):** build an n8n workflow (Webhook trigger → WhatsApp node) and set `LEAD_WEBHOOK_URL` (+ `LEAD_WEBHOOK_SECRET`). The site sends each lead as JSON.
5. **Domain + URL:** set `NEXT_PUBLIC_SITE_URL` to the production URL (drives sitemap, canonical URLs, Open Graph).
6. **Fill the placeholders:** `lib/site.ts` (email, social links, founder), a demo video in `NEXT_PUBLIC_DEMO_VIDEO_URL`, real metrics in `content/case-studies.ts`.
7. **Legal:** have `/kebijakan-privasi` reviewed (it is a template) against UU PDP.
8. **SEO:** submit `/sitemap.xml` to Google Search Console and claim your Google Business Profile.

## Deploy (Vercel)

Push to GitHub, import the repo in Vercel, add the env vars above, deploy. Pushes to `main` auto-deploy; pull requests get preview URLs. `.github/workflows/ci.yml` runs lint, typecheck, and build on every PR.

## Where to change things

|---|---|
| Prices, plans, card features | `lib/pricing.ts` (one file feeds home, /harga, /layanan, JSON-LD) |
| Brand name, tagline, contact, nav | `lib/site.ts` |
| Service descriptions | `content/services.ts` |
| Case studies | `content/case-studies.ts` |
| Blog posts | Supabase `posts` table (or `content/posts.ts` as fallback) |
| Colors, radii, shadows | `app/globals.css` + `tailwind.config.ts` |
| Form fields / validation | `lib/schema.ts`, `lib/lead-options.ts`, `components/forms/LeadForm.tsx` |
| What happens when a lead arrives | `app/actions/submit-lead.ts` |

## Publishing blog posts

Posts live in Supabase with `status = 'draft' | 'published'`. Row-level security means the public site can only ever read `published` rows. Content generated by AI should be saved as `draft`, reviewed by a human, then flipped to `published`. Pages revalidate hourly.

More detail on design decisions, security, and the feature roadmap: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Automation

Lead qualifier, weekly blog drafts, social captions, and a WhatsApp assistant run on n8n. Setup, workflows, tests and limits are in [`automation/README.md`](automation/README.md). Regenerate workflow JSON with `npm run automation:build`. Weekly SEO crawl: `npm run seo -- https://your-domain` (also runs in GitHub Actions; set the repository variable `SITE_URL`).
